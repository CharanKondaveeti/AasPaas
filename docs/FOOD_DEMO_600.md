# AasPaas Famous Food — 600 Fictional Samples

The demo intentionally contains **20 illustrated food categories × 30 synthetic entries = 600**.

## Open the demo
1. Open AasPaas → **Famous Food**.
2. Select **Preview 600 samples**, or visit `/?demo=food`.
3. Select any dish, such as Biryani or Irani Chai, to see 30 fictional test shops.
4. Try budget, food style, time, vegetarian/non-vegetarian, or search filters.
5. Turn Sample mode OFF to return to live, curator-reviewed listings.

## Data separation
- **Live production**: `public.places` / `food_dishes` / `food_hours`. No sample place is inserted in these tables.
- **Isolated sample storage**: `public.food_demo_places`. Its 600 records are synthetic, marked `is_demo=true` and `SAMPLE`, and are blocked from anonymous/authenticated direct access. Service roles can inspect it.
- **Interactive preview**: generated by `src/features/food/data/demoPlaces.ts`, matching the database seed deterministically. It does **not** query the live public places API, which avoids mixing fiction with genuine recommendations.
- **No real travel actions**: sample detail cards disable directions and WhatsApp sharing, and are plainly marked FICTIONAL SAMPLE.
- **Prices and hours**: generated UI examples, not verified or intended for real visits.
- **Map performance**: the demo starts with one selected dish (30 symbols) and caps unrestricted preview lists at 90 results so GPU map sprite memory remains bounded.

## User-facing safety
Sample badges appear on the map interface, every list row, and the detail view. Real food discovery and verified information are unchanged. **The 600 sample records do not count toward the 210 verified-food launch target.**

## Reuse
When true locations have been researched, create actual records through the normal curator pipeline rather than promoting sample records to verified.
